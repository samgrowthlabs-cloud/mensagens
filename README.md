# Private Messenger

Um aplicativo de mensagens privadas moderno e seguro, desenvolvido com HTML, CSS, JavaScript e Supabase.

## 🚀 Características

### 🔐 Segurança
- Sistema de autenticação privado
- Apenas usuários autorizados
- Máximo inicial de 10 usuários
- Sistema de banimento
- Admin principal "bidjo"

### 💬 Funcionalidades
- Mensagens privadas entre usuários
- Envio de imagens e arquivos (até 5MB)
- Edição e exclusão de mensagens
- Indicador de mensagem editada
- Status online/offline
- Busca de usuários
- Realtime para mensagens instantâneas

### 🎨 Interface
- Design premium dark
- Totalmente responsivo
- Layout otimizado para mobile
- Animações suaves
- Scrollbar customizada
- Skeleton loading
